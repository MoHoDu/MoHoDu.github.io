    새 포트폴리오

    현재 문서는 이 브라우저에 보관됩니다.

    내용을 바꾸고, 구성해 보세요.

    1. 왼쪽에서 템플릿과 요소를 고릅니다. 템플릿을 바꿔도 작성한 내용은 유지됩니다.
    2. 오른쪽에서 원고·사진·영상·표의 값을 수정합니다. 파일 업로드 또는 직접 접근 가능한 이미지·영상 URL을 사용할 수 있습니다.
    3. 요소를 드래그하거나 ↑↓로 순서를 바꾸고, 너비·높이·여백·글자 크기를 조절합니다.
    4. 편집 파일 저장은 이미지·영상을 포함한 JSON 사본입니다. 다른 PC에서 파일 열기로 이어서 수정하세요.
    5. 공유용 HTML은 편집 패널 없이 열리는 독립 파일입니다. 영상·비교·탭·색상 전환이 유지됩니다.

    자동 저장은 현재 브라우저에만 남습니다. 브라우저 데이터를 삭제하기 전 편집 파일을 저장하세요. 외부 URL은 서버의 다운로드 허용 여부에 따라 파일 내보내기가 제한될 수 있습니다. 이때 파일로 업로드하면 됩니다.

    GitHub Pages 게시에는 내보낸 결과를 배포 저장소에 반영하는 별도 단계가 필요합니다.
