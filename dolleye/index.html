핀볼의 변화가 납득되는 규칙이 되도록

유리눈을 핀볼처럼 튕겨 저주를 깨고 장난감에게 눈을 돌려주는 다크 판타지 핀볼 로그라이트입니다. Godot 기반 3인 팀에서 시스템 기획과 개발 리드를 맡았습니다.

실제 플레이

01

기획 의도와 예외

경로는 바꾸되, 지나가던 공의 흐름은 깨지 않도록.

범퍼의 내구도·파괴·복구로 경로에 변화를 주었습니다. 하지만 복구 위치에 공이 있으면 끼임이 생길 수 있었습니다. 복구 시각만 보는 대신 공의 위치와 예상 궤적을 함께 확인해야 한다고 판단했습니다.

02

기능 설계

복구를 예고하고, 접근하면 다시 기다립니다.

복구 대기에서 위치·궤적을 확인하고 생성 예고를 보여줍니다. 예고 중 공이 접근하면 대기로 돌아가며, 안전을 확인한 뒤 활성화합니다.

  1. 복구 대기
  2. 위치·궤적 검사
  3. 생성 예고
  4. 안전 확인 후 활성화
03

AI와 팀 협업

검증할 수 있는 기능 단위로 구현을 나눴습니다.

첫 웨이브 전체를 한 번에 구현했을 때 동작이 의도와 어긋나 수정 범위가 커졌습니다. 공·플리퍼·범퍼의 작업 환경과 검사 범위를 나누고, AI의 코드·자동 검사와 사람의 조작감 판단을 구분했습니다. 통합 환경에서는 기능 사이 연결을 다시 확인했습니다.

04

결과와 범위

통합 플레이를 공개하고 관찰한 결과를 기록했습니다.

팀은 웹 플레이 결과물을 공개했습니다. 안전 복구 적용 뒤 제가 확인한 플레이에서는 같은 끼임을 다시 경험하지 않았습니다. 모든 상황에서 오류가 없다는 의미는 아닙니다.

자료와 표현 범위

게임 원안·아트·레벨 디자인과 팀원 구현을 개인의 단독 기여로 포함하지 않습니다.
