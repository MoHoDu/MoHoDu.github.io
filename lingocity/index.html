초·중등생이 AI와 영어로 대화하는 스피킹 앱입니다. 자유 대화 콘텐츠 개발과 흐름 개선 제안을 맡았습니다.

01

문제와 원인 파악

한 번 틀린 뒤, 무엇에 답할 차례인지 놓쳤습니다.

공부방 테스트에서 첫 오답 뒤 같은 문항을 반복해서 틀리는 상황이 있었습니다. 로그와 직접 사용을 통해 문장 난도뿐 아니라, NPC의 응답 후 다시 답해야 할 내용을 유추하기 어려운 흐름에 주목했습니다.

02

판단과 제안

정답을 알려주기 전에 원래 질문을 다시 들려줍니다.

기존 ‘NPC 반응 → 다시 답하기’ 사이에 ‘원래 질문 다시 듣기’를 넣었습니다. 수정 프로토타입과 PPT로 회의에서 제안해 채택을 이끌었습니다.

  1. NPC 반응
  2. 원래 질문 다시 듣기
  3. 다시 답하기
03

결과

후속 테스트의 정성 평가를 확인했습니다.

다음 공부방 테스트에서 자유 대화가 조금 더 쉬워졌다는 평가를 받았습니다. 정답률·완료율이 얼마나 증가했는지는 측정 자료가 없어 수치로 제시하지 않습니다.

자료와 표현 범위
